# FMU Simulation + OPC UA + Streamlit

Runs an FMU generated by `fmugen` in Docker, exchanging its inputs and outputs through OPC UA, with a Streamlit dashboard to set inputs, launch runs and plot results.

1. **OPC UA server**: reads `modelDescription.xml` from the FMU and exposes every input/parameter under `Inputs/` and every output under `Outputs/`.
2. **FMU client**: runs the FMU with [FMPy]. Each step it reads `Inputs/` from OPC UA, steps the FMU, writes `Outputs/` back and saves a CSV.
3. **Streamlit UI**: shows outputs, edits inputs, starts one FMU client container per run, and plots the CSV.

Nothing in the stack is specific to the psychrometry model. All variable names come from the FMU, so you can swap the model by rebuilding `model/model.fmu`.

---

## Layout

```
docker/
├─ docker-compose.yml
├─ model/
│  └─ model.fmu            # generated, not committed (see below)
├─ results/                # simulation_outputs.csv, written by FMU runs
├─ opcua_server/           # opcua_server.py: creates nodes from modelDescription.xml
├─ fmu_client/             # fmu_runner_opc.py: runs the FMU, syncs with OPC UA
└─ streamlit_ui/           # streamlit_app.py: dashboard + run orchestration
```

## How to run

From the repository root, build the FMU into `docker/model/`:

```bash
uv run fmugen build src/fmu_psycrometry.py -o docker/model/model.fmu
```

Don't pass `--python` here. The FMU runs inside a Linux container, where it uses the image's `python3`.

Then, from `docker/`:

```bash
docker compose up --build
```

| Component | Endpoint |
|---|---|
| Streamlit UI | http://localhost:8501 |
| OPC UA server | `opc.tcp://localhost:4841` from the host, `opc.tcp://opcua-server:4840` inside `simnet` |

In the UI:

1. Edit inputs on the right and press **Update** to write them to OPC UA.
2. Set START/STOP/STEP in the sidebar and press **Run**. This starts an `fmu-run-<timestamp>` container.
3. Expand the run to see its logs. When it finishes, the results table and chart appear at the bottom.

Inputs are read from OPC UA on every step, so changes made during a run take effect at the next step.

After changing the model, rebuild `model/model.fmu` and restart the OPC UA server so it re-reads the variables:

```bash
docker compose restart opcua-server streamlit-ui
```

## How it fits together

```text
 Streamlit UI ── writes Inputs/, reads Outputs/ ──┐
      │                                           ▼
      │ starts via Docker socket           OPC UA server  (nodes built from model.fmu)
      ▼                                           ▲
 fmu-run-<timestamp> ── reads Inputs/, writes Outputs/ ──┘
      │
      └─► results/simulation_outputs.csv ──► Streamlit chart
```

- The `fmu-client` service in `docker-compose.yml` only builds the `fmu-client:latest` image and then idles. Actual runs are separate containers started by Streamlit.
- Run containers are siblings, not children, so their bind mounts need host paths. Streamlit finds these by inspecting its own `/model` and `/results` mounts. Set `HOST_MODEL_DIR` / `HOST_RESULTS_DIR` on the `streamlit-ui` service to override them.
- The FMU's UniFMU backend runs inside the run container, so `fmu_client/requirements.txt` includes its dependencies (`protobuf==5.27.3`, `pyzmq`). If your model imports other packages, add them there too.

## Environment variables

**fmu-client / run containers**

| Variable | Default | Description |
|---|---|---|
| `FMU_PATH` | `/app/model.fmu` (compose and Streamlit set `/model/model.fmu`) | FMU to run |
| `RESULTS_DIR` | `/results` | Where `simulation_outputs.csv` is written |
| `START_TIME` / `STOP_TIME` / `STEP_SIZE` | `0` / `10` / `1` | Simulation timing |
| `STEP_DELAY` | `0.5` | Wall-clock pause between steps, in seconds |
| `OPC_WAIT` | `5` | Seconds to wait for the OPC UA server before connecting |
| `OPCUA_ENDPOINT` | `opc.tcp://opcua-server:4840` | OPC UA server |

**opcua-server**

| Variable | Default | Description |
|---|---|---|
| `FMU_PATH` | `/model/model.fmu` | FMU whose variables are exposed |

**streamlit-ui**

| Variable | Default | Description |
|---|---|---|
| `OPCUA_ENDPOINT` | `opc.tcp://opcua-server:4840` | OPC UA server |
| `DOCKER_NETWORK` | `simnet` | Network that run containers join |
| `FMU_IMAGE` | `fmu-client:latest` | Image used for runs |
| `FMU_CONTAINER_NAME_BASE` | `fmu-run` | Prefix used to list runs |
| `HOST_MODEL_DIR` / `HOST_RESULTS_DIR` | auto-detected | Host paths for run containers' bind mounts |

## Useful commands

| Action | Command |
|---|---|
| Rebuild images | `docker compose build --no-cache` |
| Start | `docker compose up --build` |
| Stop and remove | `docker compose down` |
| Logs of a run | `docker logs fmu-run-<timestamp>` |
| Remove finished runs | `docker rm $(docker ps -aq --filter name=fmu-run-)` |
